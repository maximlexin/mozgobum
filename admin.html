Сейчас в игре

«Онлайн» — игроки, от которых за последние минуты пришли события. Считаются только те, кто разрешил облако и аналитику.

Скачивания приложения (GitHub)

Данные берутся из публичной статистики релизов GitHub. Посещаемость сайта GitHub Pages здесь не видна: её GitHub показывает только в репозитории (Insights → Traffic).

Жалобы на задания

Игроки жалуются кнопкой «Ошибка в задании?» в уроке. Жалобы сгруппированы по заданию: чем больше обращений, тем выше. «Исправлено» — вы поправили задание; «Не ошибка» — задание верное.

Промокоды

Код работает один раз на игрока. Промокоды из этого списка действуют, когда у игрока включено облако. Коды с пометкой «работает в игре без сервера» проверяются в самой игре: их нельзя выключить отсюда, а активации не считаются.
